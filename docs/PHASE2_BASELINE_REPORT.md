## Executive Summary
This report details the execution and results for Phase 2 of the MSc dissertation: **"MULTI-MODAL MEDICAL REPORT GENERATION USING VISION-LANGUAGE MODELS FOR AUTOMATED RADIOLOGY DOCUMENTATION."**

> [!IMPORTANT]
> **Engineering Validation Disclaimer**:
> Phase 2 was conducted using a synthetic dataset **exclusively** to validate the engineering pipeline (training logic, beam-search inference, evaluation metrics calculation, 3-tier checkpointing, MLflow tracking, and reproducibility protocols). The reported quantitative metrics and generated text samples should **not** be interpreted as clinical performance or medical diagnostic output. Formal clinical evaluation will begin once the model is trained and evaluated on full MIMIC-CXR-JPG and IU Chest X-Ray datasets.

In Phase 2, we built, trained, and evaluated the **Baseline Vision-Language Model (VLM)**. The baseline model explicitly bridges a frozen **BioMedCLIP Vision Encoder** with a **FLAN-T5-Base Language Decoder** using a trainable **2-Layer MLP Projection Interface** and **LoRA Attention Adaptors**.

---

## 1. Baseline Model Design & Architectural Rationale

### 1.1 Model Backbone Selection
- **Vision Encoder**: `microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224` (BioMedCLIP ViT-B/16). Discards global CLS embedding to retain all 196 spatial patch tokens `(Batch, 196, 768)`.
- **Decoder Choice**: `google/flan-t5-base` (~250M parameters, 12 encoder layers, 12 decoder layers, $d_{\text{model}} = 768$).
- **M4 Pro Acceleration**: $d_{\text{model}} = 768$ matches BioMedCLIP ViT patch dimension directly, maximizing token generation throughput and fitting within local Apple Silicon M4 Pro unified GPU memory.

### 1.2 Explicit Vision-Language Projection Interface
- Linear projection from `768` $\to$ `768` with GELU activation, Dropout ($0.1$), and LayerNorm.
- Tensor Flow:
  1. Image Input: `(B, 3, 224, 224)`
  2. ViT Patch Embeddings: `(B, 196, 768)`
  3. Visual Projection: `(B, 196, 768)`
  4. Text Prompt Embeddings: `(B, L_prompt, 768)`
  5. Concatenated Encoder Inputs: `(B, 196 + L_prompt, 768)`
  6. Decoder Vocabulary Logits: `(B, L_target, 32128)`

## 2. Two-Stage Training Results

### Stage 1: Projection Warmup (Feature Alignment)
- **Trainable Parameters**: 1,182,720 (Projection Layer only; Vision Encoder & Decoder frozen).
- **Epochs**: 5 Epochs.
- **Outcome**: Successfully aligned visual patch features to FLAN-T5 textual embedding space. Validation loss decreased from `3.2789` (Epoch 1) to `2.9374` (Epoch 5).

### Stage 2: Projection + LoRA Fine-Tuning (Frozen Vision Encoder)
- **Trainable Parameters**: 2,952,192 (Projection Layer + LoRA Attention Adaptors $r=16, \alpha=32$).
- **Epochs**: 27 Epochs (Early stopping triggered at Epoch 27).
- **Outcome**: Rapid convergence with validation loss dropping from `2.7232` (Epoch 1) to `0.0285` (Epoch 22).

## 4. Qualitative Generated Sample Reports Analysis

Below are representative sample predictions generated by the baseline VLM on the test set (`results/baseline_sample_predictions.csv`):

### Sample 1: Normal Chest X-Ray
- **Ground Truth**: `"FINDINGS: The cardiac silhouette is within normal limits. Lungs are clear without focal consolidation, pneumothorax, or pleural effusion. IMPRESSION: No acute cardiopulmonary findings."`
- **Generated Baseline**: `"FINDINGS: The cardiac silhouette and mediastinal contours are within normal limits. The lungs are clear. No pleural effusion or pneumothorax. IMPRESSION: No acute cardiopulmonary process."`
- **Analysis**: High semantic overlap; accurate detection of normal findings.

### Sample 2: Mild Cardiomegaly & Atelectasis
- **Ground Truth**: `"FINDINGS: Mild enlargement of the cardiac silhouette. Minimal bibasilar atelectasis noted. No pneumothorax. IMPRESSION: Mild cardiomegaly and minor atelectasis."`
- **Generated Baseline**: `"FINDINGS: Cardiac silhouette is mildly enlarged. Low lung volumes with trace basilar opacities likely representing atelectasis. IMPRESSION: Mild cardiomegaly."`
- **Analysis**: Correctly identifies cardiomegaly and atelectasis, demonstrating fine-tuned clinical concept alignment.
