  A defect was corrected in .gitignore during preparation: the previous pattern
  "checkpoints/*.pt" did not match files inside checkpoints/mimic_real/ or
  checkpoints/iu_real/, so roughly 15 GB of model weights would have been
  committed. The pattern is now "checkpoints/" plus "**/*.pt".


PUSHING
-------
  cd "path/to/Implementation"
  git status                       # confirm no .pt or .index files are listed
  git add -A
  git commit -m "MSc dissertation: multi-modal radiology report generation"
  git remote add origin https://github.com/<your-username>/<repo-name>.git
  git branch -M main
  git push -u origin main

  Before pushing, run this to be certain nothing large slipped through:

  git ls-files | xargs -I{} du -k "{}" 2>/dev/null | sort -rn | head -5


AFTER PUSHING
-------------
  Make the repository public, or private with access granted to the markers.
  Paste the URL into FINAL_SUBMISSION/6_Supporting_Links.pdf, Section 1.


A NOTE ON WHAT THE REPOSITORY SHOWS
-----------------------------------
  The repository contains the evidence behind Chapter 5, including the archived
  random-initialisation control in results/untrained_control/ and the root-cause
  analysis in docs/DIAGNOSTIC_FINDINGS.md. This is deliberate. The thesis reports
  four implementation defects, and a marker who inspects the code will find them
  documented rather than concealed.
